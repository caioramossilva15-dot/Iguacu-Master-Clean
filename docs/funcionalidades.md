# Funcionalidades detalhadas

## Navegação
A navegação principal funciona através um **navbar** presente no *header* de cada página, com botões que facilitam o acesso às outras páginas através de links e que ficam marcados conforme a página selecionada, como meio de melhorar a orientação do usuário ao navegar entre páginas.

Além disso a navegação possui:
- **Identidade visual própria:** Esquemas e paletas de cores presentes na logo que remetem à estética da Iguassu Master Clean;
- **Menu responsivo:** Para telas menores, a barra de navegação é substituída por uma nova barra lateral que pode ser acessada através de um *hambúrguer*, contendo os mesmos itens e links da versão para telas maiores;
- **Pesquisa responsiva:** Para telas menores, a barra de pesquisa é substituída por um botão que ativa um novo campo de pesquisa ao centro da página ;
- **Mecânica de contato:** Botão que redireciona a página para um link de contato particular da empresa via **Whatsapp**;

---

## Filtros

O sistema de filtros está presente principalmente na página de produtos, permitindo que o usuário encontre produtos de maneira mais específica através da seleção de categorias e marcas disponíveis no catálogo.

Além disso, os filtros possuem:

- **Categorias:** Permite separar os produtos de acordo com seus respectivos tipos;
- **Marcas:** Permite selecionar uma ou mais marcas parceiras para restringir os produtos apresentados;
- **Combinação de filtros:** Permite utilizar diferentes opções de filtragem para encontrar produtos que correspondam aos critérios selecionados;
- **Limpeza dos filtros:** Permite remover os filtros aplicados para retornar à visualização completa dos produtos.

---

## Responsividade

A interface possui diferentes adaptações para que o sistema possa ser utilizado em diferentes tamanhos de tela, mantendo sua organização e usabilidade.

Além disso, a responsividade possui:

- **Desktop:** Apresentação completa dos elementos de navegação, pesquisa e catálogo;
- **Tablet:** Ajuste no tamanho e posicionamento dos elementos para melhor aproveitamento da tela;
- **Mobile:** Adaptação dos elementos para telas menores, incluindo o menu lateral e a pesquisa responsiva;
- **Catálogo responsivo:** Os *cards* e demais elementos do catálogo se reorganizam conforme o espaço disponível na tela.

---

## Interações visuais

O sistema utiliza diferentes elementos visuais para tornar a navegação mais clara e dinâmica, proporcionando respostas visuais às ações realizadas pelo usuário.

Além disso, as interações possuem:

- **Hover:** Elementos como botões e links apresentam alterações visuais quando o usuário passa o cursor sobre eles;
- **Seleção:** Itens selecionados recebem indicações visuais para facilitar a identificação de filtros e opções ativas;
- **Transições:** Alguns elementos possuem transições para tornar mudanças de estado mais suaves;
- **Animações:** Elementos específicos da interface possuem animações utilizadas para complementar a navegação e apresentação visual;
- **Menus interativos:** O menu lateral e a pesquisa possuem animações e alterações visuais durante sua abertura e fechamento.
